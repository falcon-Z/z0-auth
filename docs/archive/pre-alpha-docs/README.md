# Pre-Alpha documentation archive

This directory preserves documentation from the product and implementation model that existed before the current Z0Auth Alpha baseline.

The material is historical reference only. It may describe app-local users, Service Group SSO, opaque access tokens, token introspection, older federation behavior, older deployment assumptions, or other contracts that conflict with the approved Alpha model.

Do not use files in this directory as the current integration, deployment, API, security, or product contract.

Useful examples or operational details may be brought back into active documentation only after they are checked against the current Alpha design, implementation, and tests.
